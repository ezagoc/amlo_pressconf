# Grupo Canton Cluster

Research date: 2026-08-10

Scope: Diario Basta, Tabasco Hoy, Quintana Roo Hoy, Campeche Hoy.

## Summary

These four outlets should be treated as a single media-family cluster under Grupo Canton. The workbook already points in this direction through `bene_final = grupo canton` and shared COMSOC/conference names. Public sources also connect the brands to Grupo Canton and to Miguel Canton Zetina.

Suggested shared metadata:

| Field | Suggested value |
| --- | --- |
| owner_group | Grupo Canton |
| director_general | Miguel Canton Zetina |
| media_family | Grupo Canton / Organizacion Editorial Acuario and related companies |
| ideology.subjective | aligned / pro-4T |
| ideology_confidence | medium to medium-high, depending on outlet |
| ideology_basis | Grupo Canton self-description around the 4T, AMLO-era mañanera participation, and external reporting on federal publicity/favorable coverage |

## Ideology / Alignment Note

Recommended coding: `aligned` or `pro-4T`, with `confidence = medium` for the cluster and `medium-high` for Diario Basta and Tabasco Hoy.

This is an interpretive field, so keep a source and basis note. The strongest basis is not a single ideological manifesto, but a convergence of evidence:

- Grupo Canton articles associate Basta and the group with the Cuarta Transformacion / AMLO-era political environment.
- AMLO's official mañanera transcript identifies a Grupo Canton reporter representing Tabasco Hoy, Diario Basta, Quintana Roo Hoy, and Campeche Hoy.
- External criticism alleges federal publicity contracts and favorable coverage toward AMLO.
